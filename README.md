# Obstacle Detection Alert System Using Arduino

## Project Overview
This project uses an Arduino Uno and HC-SR04 Ultrasonic Sensor to detect nearby obstacles and alert the user using an LED and buzzer.

## Components Used
- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- LED
- 220Ω Resistor
- Buzzer
- Breadboard
- Jumper Wires
- USB Cable / Power Bank

## Working Principle
The ultrasonic sensor sends sound waves and receives the reflected waves from nearby objects. Arduino calculates the distance and activates the LED and buzzer when an obstacle comes within the predefined range.

## Applications
- Smart Parking Systems
- Robotic Navigation
- Blind Assistance Devices
- Industrial Safety Systems
